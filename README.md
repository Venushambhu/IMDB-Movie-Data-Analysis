# IMDb Movie Data Analysis

## Project Overview
This project analyzes IMDb movie data to extract insights into trends, ratings, genres, and other key aspects of the movie industry. The analysis includes data wrangling, exploratory data analysis (EDA), and visualization to uncover meaningful patterns in the dataset.

## Dataset
The dataset used for this project contains information about movies, including:
- Movie titles
- Release year
- IMDb ratings
- Genres
- Directors and actors
- Revenue and budget
- Runtime

## Objectives
- Analyze the distribution of IMDb ratings.
- Identify trends in movie genres over time.
- Investigate the relationship between budget and revenue.
- Explore the impact of directors and actors on movie success.
- Provide data-driven insights through visualization.

## Technologies Used
- **Python** (Pandas, NumPy, Matplotlib, Seaborn, SciPy)
- **Jupyter Notebook** for interactive analysis
- **CSV** files for data storage

## Installation
To run the project locally, follow these steps:
1. Clone the repository:
   ```sh
   git clone https://github.com/yourusername/imdb-movie-analysis.git
   ```
2. Navigate to the project directory:
   ```sh
   cd imdb-movie-analysis
   ```
3. Create a virtual environment (optional but recommended):
   ```sh
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```
4. Install required dependencies:
   ```sh
   pip install -r requirements.txt
   ```

## Usage
- Open the Jupyter Notebook:
  ```sh
  jupyter notebook
  ```
- Run the `IMDB_Analysis.ipynb` notebook to explore the dataset and generate insights.

## Results & Insights
- The analysis reveals patterns in IMDb ratings across different movie genres and time periods.
- Budget and revenue analysis show trends in profitability.
- Visualizations provide insights into the top-performing directors and actors.
